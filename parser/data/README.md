# okpd2.json

Справочник ОКПД2 (ОК 034-2014, КПЕС 2008): пары `[код, название]`, только коды продукции (без разделов-букв).

Источник: [ofdata.ru — открытые данные](https://ofdata.ru/open-data), файл `okpd_2.json.zip`, версия от 23.02.2022.
Лицензия: [CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/).

Коды, которых нет в этой версии справочника, получают название по самому частому товару с этим кодом в данных закупок.
